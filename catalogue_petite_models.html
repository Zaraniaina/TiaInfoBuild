1. Modèles de Classification d’images (les plus utiles pour toi)

Modèle Taille approx. (quantized) Utilité principale Sur quoi le fine-tuner ?
MobileNetV3-Large ~5.8 MB Classification générale très équilibrée Maladies de la peau, plantes, aliments, émotions, déchets…
MobileNetV3-Small ~2.5–3 MB Ultra-léger, temps réel Même choses que Large mais priorite vitesse
MobileNetV2 ~3.5–4 MB Très stable et documenté Baseline classique pour presque tout
EfficientNet-B0 ~6–7 MB Meilleure précision parmi les légers Peau, radiographie, fruits, animaux…
EfficientNet-Lite0 ~4–5 MB Optimisé spécialement mobile Idem EfficientNet-B0
ShuffleNetV2 ~3–5 MB Extrêmement rapide sur CPU mobile Classification temps réel
SqueezeNet ~1.5–3 MB Très petite taille Quand la taille est critique
MobileViT / FastViT ~5–10 MB Hybride CNN + Transformer Quand tu veux un peu plus de précision
Conseil : Pour un mémoire solide, compare toujours 2 ou 3 de ces modèles (ex: MobileNetV3-Large vs EfficientNet-B0 vs ShuffleNetV2).

4. Idées de thèmes de mémoire (avec ces petits modèles)

1. Thème original (le tien amélioré)
Classification offline des maladies de la peau avec MobileNetV3-Large + EfficientNet-B0 + application Flutter.
2. Détection + Classification
Utiliser YOLOv8n / YOLOv11n pour détecter et classer les lésions cutanées en temps réel sur smartphone (bounding box + nom de la maladie).
3. Comparaison multi-modèles
Étude comparative de 4 modèles légers (MobileNetV3, EfficientNet-Lite, ShuffleNetV2, YOLOv8n) sur HAM10000 + mesure taille / vitesse / précision sur téléphone réel.
4. Segmentation + Classification
Combiner un modèle de segmentation léger (DeepLab-MobileNet) + un classificateur pour mieux isoler la lésion avant de la classer.
5. Autres domaines médicaux
- Classification de rétinopathie diabétique (images du fond d’œil)
- Classification de pneumonie / COVID sur radiographies thoraciques
- Détection de caries dentaires à partir de photos
6. Agriculture / Environnement
- Détection de maladies des plantes (PlantVillage dataset)
- Classification de déchets pour le tri intelligent
- Détection d’insectes nuisibles
7. Accessibilité / Société
- Reconnaissance d’émotions faciales pour l’autisme ou la santé mentale
- Détection de gestes pour contrôler une application sans toucher
- Aide à la lecture pour malvoyants (description d’objets)
8. Version plus avancée
Fine-tuner un très petit VLM (SmolVLM) pour qu’il non seulement classe la maladie de la peau mais génère aussi une petite explication en français.

5. Conseil final pour choisir ton thème

Pour un master réaliste et bien noté, je te recommande de rester dans cette zone :

  • Modèle(s) : MobileNetV3-Large + EfficientNet-B0 (ou YOLOv8n si tu veux de la détection)
  • Tâche : Classification (ou détection) de maladies de la peau
  • Contrainte forte : Application mobile 100 % offline
  • Bonus : Quantization + mesure de performance sur vrai téléphone + Grad-CAM

C’est clair, faisable, actuel, et très apprécié des jurys.
